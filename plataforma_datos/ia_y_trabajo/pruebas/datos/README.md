# Capturas reales para las pruebas

Copias completas, byte a byte, de páginas y tablas de terceros (Idescat e INE) con que las pruebas comprueban la
lectura y la navegación de las fuentes. Cada archivo lleva su dirección de origen y su huella en la procedencia que
tiene al lado (`procedencia-idescat-ticll25.json`; `ine-tich/procedencia.json`, que describe también las páginas
`ine-tich-2026-*.html` y da la fecha de captura).

Las páginas HTML están excluidas de Biome (`biome.json`): son de terceros y no se pueden corregir ni formatear sin dejar
de coincidir con su huella.
