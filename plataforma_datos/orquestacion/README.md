# Cadena de datos

La orquestación coordina la lectura, preparación, comprobación y exportación de datos. Los comandos de
las guías se ejecutan desde la raíz del producto. Los productores viven en sus temas de
[plataforma de datos](../README.md); las utilidades compartidas están en `plataforma_datos/comun/`.
